*** Test Case ***


# Positive Tests

Create blank project
    Navigate to Projects page
    Click "New project"
    Select "Create blank project"
    Input Project Name ProjectName
	Pick Project URL group or namespace
    Click Create project button
    Verify page should contain "Project 'XYZ' was successfully created."

Create template project
    Navigate to Projects page
    Click "New project"
    Select "Create from template"
    Choose template project
    Input Project Name ProjectName
	Pick Project URL group or namespace
    Click Create project button
    Verify page should contain "The project was successfully imported."

Update name of template project
    Navigate to template project
    Click three dots on the right and pick Edit
    Update project name 
    Save changes
    Verify page should contain "Project 'XYZZ' (new name) was successfully updated."

Delete template project
    Navigate to template project
    Click three dots on the right and pick Delete
    Input the project path to confirm
    Click Yes, delete project button. 
	Verify page should contain "XYZ moved to pending deletion."
    Verify project is removed from project list.
	Choose Inactive Projects.
	Click three dots of the deleted project. 
	Pick Delete Permanently.
	Input the project path to confirm.
	Select the box: "This action permanently deletes this project and all its data. Your administrator cannot restore it."
	Click Yes, delete project button.
	Verify project is removed from inactive projects list.
